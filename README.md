# Campus Placement Management System — Web Frontend

A browser-based frontend for the Campus Placement Management System, created from the original C++17 project.

## Original C++ scope
The C++ prototype supports:
- Student and recruiter menus
- Job listings
- Eligibility matching by CGPA, backlogs and required skills
- Duplicate application prevention
- Application status tracking
- Recruiter job posting and status updates
- Student dashboard counters

## Web version
The Netlify version provides a visual frontend for these same workflows:
- Student dashboard
- Job search and filtering
- Eligibility indicators
- Apply workflow
- Application tracking
- Student profile and skills
- Recruiter dashboard
- Job posting form
- Application status updates
- Responsive design
- Created by Ashish Yadav

## Important
This is a frontend/demo version. Data is held in browser memory and is not a production backend. The original C++ program stores its records in memory and resets when it exits.

## Deploy on Netlify
1. Upload these files to a GitHub repository.
2. In Netlify choose **Add new project → Import an existing project → GitHub**.
3. Select the repository.
4. Branch: `main`
5. Build command: leave empty
6. Publish directory: `.`
7. Deploy.

No Node.js, npm or build step is required.
